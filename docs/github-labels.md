# Suggested GitHub Labels

- `good first issue`: safe starter tasks with clear scope and no proprietary material.
- `help wanted`: maintainers want outside help and the issue has enough context.
- `docs`: README, architecture docs, troubleshooting, examples.
- `tests`: pytest coverage, synthetic fixtures, acceptance helper improvements.
- `raspberry-pi`: Raspberry Pi OS, audio output, service setup, packaging.
- `mpv`: mpv JSON IPC, playback behavior, filters, process management.
- `discovery`: SSDP, mDNS, description XML, LAN visibility.
- `audio`: playback quality, volume, balance, PEQ, audio stack behavior.
- `bug`: confirmed or likely defect.
- `privacy`: log redaction, accidental identifiers, unsafe defaults.
- `legal-risk`: trademark, proprietary material, raw dump, or policy concern.
- `needs-repro`: issue needs a minimal sanitized reproduction.
- `blocked`: blocked on external behavior, hardware access, or missing safe data.
